# E-LIST-EMPTY

**Error: blocks publishing** · stage 3, Meaning

## What it means

Choice list "‹list›" has no choices.

## How to fix it

Add choices for it on the choices sheet.

## Example

An upload that triggers it reports:

> Choice list "v.csv" has no choices.
>
> → Add choices for it on the choices sheet.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
