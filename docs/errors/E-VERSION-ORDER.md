# E-VERSION-ORDER

**Error: blocks publishing** · stage 3, Meaning

## What it means

Version "‹version›" is not newer than the published version "‹published›".

## How to fix it

Set a higher value in the version setting.

## Example

An upload that triggers it reports at `settings!B2`:

> settings!B2: Version "2024-01" is not newer than the published version "2025-03".
>
> → Set a higher value in the version setting.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
