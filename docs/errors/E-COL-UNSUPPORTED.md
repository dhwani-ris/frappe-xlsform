# E-COL-UNSUPPORTED

**Error: blocks publishing** · stage 2, Structure

## What it means

Column "‹column›" isn't supported.

## How to fix it

Remove the column; it changes how answers are stored, so it can't be ignored.

## Example

An upload that triggers it reports at `survey!D1`:

> survey!D1: Column "trigger" isn't supported.
>
> → Remove the column; it changes how answers are stored, so it can't be ignored.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
