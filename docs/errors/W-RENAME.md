# W-RENAME

**Warning: publish after ticking “I understand”** · stage 5, Changes from the published version

## What it means

‹old› was removed and ‹new› added; existing answers to ‹old› won't move to the new question.

## How to fix it

Keep the old name if it's the same question.

## Example

An upload that triggers it reports at `survey!B2`:

> survey!B2: village was removed and village_name added; existing answers to village won't move to the new question.
>
> → Keep the old name if it's the same question.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
