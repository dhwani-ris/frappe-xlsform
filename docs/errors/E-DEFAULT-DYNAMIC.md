# E-DEFAULT-DYNAMIC

**Error: blocks publishing** · stage 3, Meaning

## What it means

The default "‹value›" can't be used; defaults must be fixed values, today() or now().

## How to fix it

Use a fixed value, or a calculate question.

## Example

An upload that triggers it reports at `survey!D3`:

> survey!D3: The default "${a}" can't be used; defaults must be fixed values, today() or now().
>
> → Use a fixed value, or a calculate question.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
