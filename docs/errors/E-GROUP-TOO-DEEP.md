# E-GROUP-TOO-DEEP

**Error: blocks publishing** · stage 2, Structure

## What it means

Row ‹row› opens a ‹kind› inside ‹depth› other groups or repeats; the limit is ‹limit›.

## How to fix it

Close some groups before opening new ones, so fewer groups are inside each other.

## Example

An upload that triggers it reports at `survey!A32`:

> survey!A32: Row 32 opens a group inside 30 other groups or repeats; the limit is 30.
>
> → Close some groups before opening new ones, so fewer groups are inside each other.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
