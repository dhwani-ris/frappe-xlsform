# E-FILE-TYPE

**Error: blocks publishing** · stage 1, File

## What it means

This file is not an Excel workbook (.xlsx).

## How to fix it

Save it as .xlsx from Excel or Google Sheets and upload again.

## Example

An upload that triggers it reports:

> This file is not an Excel workbook (.xlsx).
>
> → Save it as .xlsx from Excel or Google Sheets and upload again.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
