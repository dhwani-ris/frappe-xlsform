# E-FILE-CSV-MISSING

**Error: blocks publishing** · stage 3, Meaning

## What it means

Row ‹row› uses ‹file›, which wasn't uploaded with the form.

## How to fix it

Upload ‹file› together with the workbook.

## Example

An upload that triggers it reports at `survey!A2`:

> survey!A2: Row 2 uses v.csv, which wasn't uploaded with the form.
>
> → Upload v.csv together with the workbook.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
