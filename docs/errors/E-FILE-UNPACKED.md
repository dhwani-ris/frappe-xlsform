# E-FILE-UNPACKED

**Error: blocks publishing** · stage 1, File

## What it means

The workbook unpacks to ‹size_mb› MB of data; the limit is ‹limit_mb› MB.

## How to fix it

Remove embedded images and unused sheets, save it again as .xlsx and upload the new file.

## Example

An upload that triggers it reports:

> The workbook unpacks to 0.1 MB of data; the limit is 0.05 MB.
>
> → Remove embedded images and unused sheets, save it again as .xlsx and upload the new file.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
