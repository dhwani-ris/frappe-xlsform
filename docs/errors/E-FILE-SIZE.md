# E-FILE-SIZE

**Error: blocks publishing** · stage 1, File

## What it means

The file is ‹size_mb› MB; the limit is ‹limit_mb› MB.

## How to fix it

Remove embedded images or unused sheets.

## Example

An upload that triggers it reports:

> The file is 0 MB; the limit is 0.001 MB.
>
> → Remove embedded images or unused sheets.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
