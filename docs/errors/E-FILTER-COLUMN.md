# E-FILTER-COLUMN

**Error: blocks publishing** · stage 3, Meaning

## What it means

choice_filter uses column "‹choice_column›", which isn't on the choices sheet for list "‹list›".

## How to fix it

Add a "‹choice_column›" column to the choices sheet.

## Example

An upload that triggers it reports at `survey!D3`:

> survey!D3: choice_filter uses column "state", which isn't on the choices sheet for list "v".
>
> → Add a "state" column to the choices sheet.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
