# I-NO-LABEL

**Advice** · stage 3, Meaning

## What it means

Row ‹row› (‹name›) has no label, so collectors will see only its name.

## How to fix it

Add a label.

## Example

An upload that triggers it reports at `survey`:

> Row 2 (a) has no label, so collectors will see only its name.
>
> → Add a label.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
