# E-CHOICE-NAME

**Error: blocks publishing** · stage 3, Meaning

## What it means

Choice name "‹choice›" in list "‹list›" ‹reason›.

## How to fix it

Use ‹fixed›; the label can keep any text.

## Example

An upload that triggers it reports at `choices!B2`:

> choices!B2: Choice name "not sure" in list "c" contains a space.
>
> → Use not_sure; the label can keep any text.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
