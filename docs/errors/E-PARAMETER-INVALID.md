# E-PARAMETER-INVALID

**Error: blocks publishing** · stage 3, Meaning

## What it means

Parameter "‹parameter›" (row ‹row›) has the value "‹value›", which isn't a number.

## How to fix it

Use a number, e.g. ‹parameter›=10.

## Example

An upload that triggers it reports at `survey!D2`:

> survey!D2: Parameter "start" (row 2) has the value "one", which isn't a number.
>
> → Use a number, e.g. start=10.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
