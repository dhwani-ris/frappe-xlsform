# E-CALC-CYCLE

**Error: blocks publishing** · stage 3, Meaning

## What it means

These calculations depend on each other in a loop: ‹cycle›.

## How to fix it

Break the loop so one of them doesn't use the other.

## Example

An upload that triggers it reports at `survey!D3`:

> survey!D3: These calculations depend on each other in a loop: share → total → share.
>
> → Break the loop so one of them doesn't use the other.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
