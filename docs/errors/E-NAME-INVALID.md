# E-NAME-INVALID

**Error: blocks publishing** · stage 2, Structure

## What it means

"‹name›" can't be used as a name: ‹reason›.

## How to fix it

Use ‹fixed›.

## Example

An upload that triggers it reports at `survey!B2`:

> survey!B2: "Household size" can't be used as a name: names can't contain spaces.
>
> → Use household_size.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
