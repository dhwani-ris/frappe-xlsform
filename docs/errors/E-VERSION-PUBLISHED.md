# E-VERSION-PUBLISHED

**Error: blocks publishing** · stage 3, Meaning

## What it means

Version "‹version›" of this form is already published.

## How to fix it

Set a new, higher version in the settings sheet.

## Example

An upload that triggers it reports at `settings!B2`:

> settings!B2: Version "2025-03" of this form is already published.
>
> → Set a new, higher version in the settings sheet.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
