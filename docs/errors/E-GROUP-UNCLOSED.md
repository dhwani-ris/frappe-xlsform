# E-GROUP-UNCLOSED

**Error: blocks publishing** · stage 2, Structure

## What it means

The ‹kind› started in row ‹row› (‹name›) is never closed.

## How to fix it

Add an ‹end› row where the ‹kind› should end.

## Example

An upload that triggers it reports at `survey!A2`:

> survey!A2: The group started in row 2 (g) is never closed.
>
> → Add an end_group row where the group should end.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
