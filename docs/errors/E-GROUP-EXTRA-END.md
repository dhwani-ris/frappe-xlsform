# E-GROUP-EXTRA-END

**Error: blocks publishing** · stage 2, Structure

## What it means

Row ‹row› closes a ‹kind› that was never opened.

## How to fix it

Delete row ‹row›, or add the matching begin row above it.

## Example

An upload that triggers it reports at `survey!A3`:

> survey!A3: Row 3 closes a group that was never opened.
>
> → Delete row 3, or add the matching begin row above it.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
