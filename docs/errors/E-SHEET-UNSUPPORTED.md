# E-SHEET-UNSUPPORTED

**Error: blocks publishing** · stage 1, File

## What it means

The "‹sheet_name›" sheet (entities) isn't supported yet.

## How to fix it

Remove the sheet; Frappe DocTypes already store each record.

## Example

An upload that triggers it reports at `entities`:

> The "entities" sheet (entities) isn't supported yet.
>
> → Remove the sheet; Frappe DocTypes already store each record.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
