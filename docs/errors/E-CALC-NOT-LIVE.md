# E-CALC-NOT-LIVE

**Error: blocks publishing** · stage 3, Meaning

## What it means

"‹column›" uses ‹name›, whose calculation can only run when the form is saved.

## How to fix it

Write the condition without ‹name›, or simplify its calculation.

## Example

An upload that triggers it reports at `survey!D4`:

> survey!D4: "relevant" uses age, whose calculation can only run when the form is saved.
>
> → Write the condition without age, or simplify its calculation.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
