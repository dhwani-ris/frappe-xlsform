# E-NAME-MISSING

**Error: blocks publishing** · stage 2, Structure

## What it means

Row ‹row› has a question type but no name.

## How to fix it

Add a short name, e.g. ‹example›.

## Example

An upload that triggers it reports at `survey!B2`:

> survey!B2: Row 2 has a question type but no name.
>
> → Add a short name, e.g. household_size.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
