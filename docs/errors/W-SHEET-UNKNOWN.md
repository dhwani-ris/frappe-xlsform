# W-SHEET-UNKNOWN

**Warning: publish after ticking “I understand”** · stage 1, File

## What it means

The sheet "‹sheet_name›" isn't used, so anything on it will be ignored.

## How to fix it

Did you mean "‹guess›"? Rename the sheet if so.

## Example

An upload that triggers it reports:

> The sheet "stettings" isn't used, so anything on it will be ignored.
>
> → Did you mean "settings"? Rename the sheet if so.

Words in ‹angle quotes› above are filled in with your form's own names, rows and values.
